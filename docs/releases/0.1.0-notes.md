# Ond 0.1.0

Ondを第三者が試せる形にした、最初の開発者向けリリースです。

## 主な内容

- Ond v1の言語仕様と利用者向けマニュアル
- target非依存のfrontend、型検査、HIR、MIR、validator
- Kagura v1向けbackend、Object、linker、LinkedImage
- 複数package、path／Git依存、lockfile、差分build cacheに対応した`ond` CLI
- 補完、hover、定義参照、参照検索、rename、semantic tokens、診断を提供する`ond-lsp`
- compiler、backend、CLI、Language Serverの回帰テストと適合テスト

## 配布物

- GitHubのsource archive
- `ond-0.1.0-windows-x86_64.zip`
  - `ond.exe`
  - `ond-lsp.exe`
  - README、変更履歴、MIT License
- ZIPのSHA-256ファイル

正式な検証環境はWindows x64とRust 1.91.1です。LinuxとmacOSは0.1.0では未検証です。

## 安定性

0.1.0は開発者向けの初期リリースです。言語、ABI、MIR、Object／LinkedImage、Rust公開APIの
後方互換性はまだ保証しません。0.1系列では重大な不具合の修正と文書化された標準経路の
再現性を優先し、破壊的な変更は原則として0.2.0で行います。

利用方法と既知の制約はREADMEおよびOnd言語マニュアルを参照してください。
