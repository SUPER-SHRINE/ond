# Ond 0.1.3（リリース準備中）

配布binaryの第三者ライセンス情報と、archive／Language Serverを照合するmanifest v1を収録します。

## 配布物

- `ond-0.1.3-windows-x86_64.zip` と `.sha256`
- `ond-0.1.3-linux-x86_64.tar.gz` と `.sha256`
- `ond-0.1.3-manifest.json`

両archiveにはbinary 2件、README・CHANGELOG・LICENSE、0.1.2から継続する設計文書6件、
`THIRD-PARTY-NOTICES.txt`、およびRust standard library由来の
`COPYRIGHT-library.html`を元の相対pathで収録します。第三者ライセンスの詳細は同梱noticeを参照してください。

manifest v1のschemaと検証方法は0.1.2から変更しません。拡張側は従来どおり
archive名、SHA-256 sidecar、`ond-0.1.3-manifest.json`を使用できます。両noticeファイルを
archive rootから読み取れます。

拡張が`ond-lsp`をVSIXへ同梱する場合は、archive rootの`THIRD-PARTY-NOTICES.txt`と
`COPYRIGHT-library.html`を変更せず、binaryと同じ場所へコピーしてください。Ond本体のMIT licenseは
引き続き`LICENSE.md`にあります。

## リリース前の確認

WindowsとUbuntuのFull品質検査、Release smoke testを通した後に公開してください。
`tools/package-release.ps1 -Version 0.1.3`はnative archive、SHA-256 sidecarと検証用descriptorを生成します。
両targetの出力を同じdirectoryへ集め、`tools/release-manifest.ps1 -Mode Generate -Version 0.1.3 -Commit <Git HEAD> -AssetDirectory <directory>`でmanifestを生成します。
descriptorはReleaseへ公開しません。
