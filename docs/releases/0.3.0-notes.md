# Ond 0.3.0

0.3.0では、interface型を廃止し、projectと依存packageの指定方法、test build、言語仕様と適合caseを更新しました。\
利用者向けの変更一覧は[CHANGELOG](../../CHANGELOG.md)、規範契約は[仕様索引](../../specs/README.md)を参照してください。

## 互換性に関わる変更

### interface型の廃止

組込み`interface`型、interface変換、interfaceによる動的dispatchを削除しました。\
動的dispatchが必要な場合は、通常の`struct`とfunction pointerを組み合わせて表現してください。

### project名と依存package

全projectで`ond.toml`の`[project].name`が必須になり、import pathは対象project名から始まります。\
依存packageはmanifestの`[dependencies]`へ登録してください。\
`OND_PATH`環境変数と`--library-dir` optionによる依存指定は利用できません。

依存登録名、import path、source探索の契約は[package仕様](../../specs/ond/build/packages.md)と[名前・import仕様](../../specs/ond/language/v1/names-and-scopes.md)を参照してください。

## test build

`ond compile --test`で実行projectまたはlibrary projectのtest buildを選べるようになりました。\
file出力のlinkではLinkedImageと並べて`.ondtest` sidecarを生成します。\
Language Serverは通常/test source集合を区別してpackage単位に解析を再利用し、test宣言の補完を扱います。

操作と出力形式は[build command仕様](../../specs/ond/build/commands.md)、[test build仕様](../../specs/ond/build/test-build.md)、[成果物仕様](../../specs/ond/artifacts.md)を参照してください。

## 言語・診断の変更

`len` operatorは`u32`ひとつを返す契約になりました。\
配列`len`の評価と定数式での適格性を整理し、狭い符号付き整数の負値を配列indexに使う場合の範囲検査を修正しました。\
generic具体化に由来する診断では定義位置と使用位置をまとめ、暗黙数値helperの呼び出し範囲を`Call`、範囲外のf32から整数への変換faultを`InvalidConversion`として分類します。

配列literal内の短絡式で通常callを含むconst initializerはcompile errorになります。\
従来誤って受理されていたこの形式は、通常callを含まない定数式へ書き換えてください。

各規則の定義元は[operator仕様](../../specs/ond/language/v1/expressions.md#user-defined-operator)、[組み込み`len`仕様](../../specs/ond/language/v1/builtins.md#4-len)、[宣言・const仕様](../../specs/ond/language/v1/declarations.md#宣言)、[debug metadata仕様](../../specs/ond/debug-metadata/v1.md)です。

## 仕様と適合case

言語、build、成果物、debug metadataの規範契約を`specs/ond/`へ整理し、適合要件と入力・期待結果のcaseを再編しました。\
参照先は[適合要件](../../specs/ond/conformance/requirements.md)と[適合case索引](../../specs/ond/conformance/cases/README.md)です。
