# Ond 0.1.2

配布物を拡張側で検証するためのmanifest v1を追加します。
マシン機能の設計文書とロードマップも収録します。
資料は非規範の将来案であり、machine runtime、GUI、新コマンドの提供やABIの確定を意味しません。

## 配布物

- `ond-0.1.2-windows-x86_64.zip` と `.sha256`
- `ond-0.1.2-linux-x86_64.tar.gz` と `.sha256`
- `ond-0.1.2-manifest.json`

両OSのarchiveには、binary2件とREADME・CHANGELOG・LICENSEに加えて、
`docs/design/README.md`と関連する5文書を元の相対pathで収録します。
展開後は`docs/design/README.md`から読み始めてください。

manifestは`schemaVersion: 1`、repository、version、実Git commitと両targetを記録します。
各targetにはrustTarget、archiveのname／SHA-256／byte size、展開したLSPのname／SHA-256を含めます。
全階層のkeyは辞書順、targetsはtarget昇順、UTF-8（BOMなし）とLF末尾改行のcompact JSONです。
manifestはbinary由来の証拠のみを含み、sourceやcache、公開後に割り当てられるasset IDは含めません。
