# Ond 0.5.0

Ond 0.5.0では、64ビット整数型、倍精度浮動小数点型、固定小数点型を追加しました。\
Kagura向けABIとビルド成果物の版も変わるため、0.4.0から更新する際はソースから再ビルドしてください。

変更一覧は[CHANGELOG](../../CHANGELOG.md)にまとめています。

## 数値型の追加

| 型 | 表現 |
| --- | --- |
| `u64`、`i64` | 64ビットの符号なし整数、符号付き整数 |
| `f64` | 64ビットの倍精度浮動小数点数 |
| `q16`、`q32` | 小数部が16ビット、32ビットの符号付き固定小数点数 |

新しい型は変数、定数、関数の引数と戻り値に使えます。\
型の範囲と変換は[型仕様](../../specs/ond/language/v1/types.md)、小数を使う例は[小数の値](../manual/language-tour/values/floats.md)を参照してください。

## 0.4.0からの更新

Kagura v1向けの呼び出し規約は `ond-kagura-v2` になりました。\
ビルド中間成果物の契約はrevision `8`、実行バイナリのONDX ABI識別子は `2` です。

0.5.0の `ond compile` と `ond link` でプロジェクトと依存パッケージを再ビルドし、ONDXを読み込む環境も新しいABIに対応した版を使ってください。\
アセンブリや外部コードで使う呼び出し規約は[Kagura ABI仕様](../../specs/ond/targets/kagura-v1/abi.md)、成果物の受理条件は[版識別と互換条件](../../specs/ond/artifacts.md#版識別と互換条件)で確認できます。

Kagura向けの構造体で、末尾パディングを含むサイズが `u32` の上限を超えた場合はコンパイルエラーです。\
サイズの上限は[Kaguraのデータ配置](../../specs/ond/targets/kagura-v1/machine.md#5-data-layout)を参照してください。

## ソース探索とエディター

ソース探索では `[resolve].ignore` に従ってディレクトリを除外します。\
`*` や `[` もディレクトリ名の一部です。\
設定例は[`ond.toml` リファレンス](../manual/reference/manifest.md#projectとsource探索)を参照してください。

Language Serverでは、識別子の入力途中でもローカル変数や引数が補完候補になります。\
演算式で初期化した変数のホバーに推論型を表示し、宣言表示の余分な空白も取り除きました。

## Kagura向けコード生成

適用条件を満たす計算では、整数の剰余に先に求めた商を使い、`f32` への往復変換や演算の一部で命令を省きます。\
添字が範囲内と分かる配列の境界検査、ポインター走査のアドレス計算、非公開のローカル配列のコピーや戻り値の転送も最適化の対象です。\
通常コンパイルでの動作は[ビルドと起動の手順](../manual/getting-started/build-and-launch.md)を参照してください。

集約値の転送でfaultが発生した場合、デバッグ情報は問題のアクセスを読み取りまたは書き込みに分類します。

## 配布とインストール

配布先は Windows x64 と Linux x86_64（glibc）です。\
Windows用のインストーラーとZIP、Linux用の `.tar.gz` に `ond`、`ond-lsp`、`ond-unit` が含まれます。\
ファイル名と導入手順は[インストールガイド](../manual/getting-started/installation.md)を参照してください。
