# Ond 0.1.1

Linux x86_64（glibc）での開発・検証経路を追加するパッチリリースです。
言語仕様、ABI、Object形式、依存するKagura 0.1.0は変更しません。
developのロゴ更新も含みます。

## 配布物

- `ond-0.1.1-windows-x86_64.zip` と `.sha256`
- `ond-0.1.1-linux-x86_64.tar.gz` と `.sha256`

Linux archiveには実行可能な`ond`と`ond-lsp`を同梱します。`tar -xzf`で展開し、
`ond compile`、`ond link`、`ond-lsp stdio`を使用してください。
配布CIはUbuntu 22.04、Rust 1.91.1を使用します。別環境で作ったbinaryのglibc要件は
ビルド元に依存します。ARM64、Alpine/musl、macOS向けbinaryは含みません。
