# Ond 0.4.0

0.4.0では、実行fileの形式とbuild設定を更新しました。\
project role、Kagura向けinline assembly、Windows installer、ユーザー向け文書サイトを追加しています。\
利用者向けの変更一覧は[CHANGELOG](../../CHANGELOG.md)、規範契約は[仕様索引](../../specs/README.md)を参照してください。

## 互換性に関わる変更

### 実行fileとbuild設定

`ond link`はONDX形式の実行可能バイナリを生成し、既定の出力先は`.ond/target/a.bin`です。\
compile manifestは`.ond/target/build.ondbuild`、package cacheは`.ond/target/ond-cache`を使います。\
debug sidecarは実行fileと同じdirectoryに`.onddebug`拡張子で出力します。\
build中間成果物とdebug sidecarの内容は引き続きJSON形式です。\
`ond.toml`の`[link].startup`では、外部loaderが起動する`external`と、file内の起動処理を使う`self`を選択できます。\
ROM/RAM領域、stack容量、終了後の動作も`[link]`設定で指定してください。

compileとlinkの設定、入出力形式は[build command仕様](../../specs/ond/build/commands.md)、[packageとcompile/link設定](../../specs/ond/build/packages.md)、[成果物仕様](../../specs/ond/artifacts.md)を参照してください。

### Test buildの廃止

`ond compile --test`と`.ondtest` sidecarを廃止しました。\
`test.ond`および`*_test.ond`も通常のsourceとして扱います。\
テスト対象の選定、起動用sourceやmetadataの生成、実行と結果判定は、外部toolまたは利用側のcodeで行ってください。\
contract revisionは7です。\
古いcacheは再生成されます。

source探索とcacheの規則は[package仕様](../../specs/ond/build/packages.md)、[cache仕様](../../specs/ond/build/cache.md)を参照してください。

## Project role

`ond.toml`の`[roles]`でprojectの追加roleを宣言し、実行projectでは`ond compile --role NAME`で選択できます。\
final projectは依存先ごとにroleを指定できます。Language Serverはrole構文に応じた解析と補完に対応しました。\
依存roleと`project.final`の条件に合わせてmanifestを更新してください。

選択と依存境界は[project role仕様](../../specs/ond/build/roles.md)、source上のrole構文は[Language v1 role仕様](../../specs/ond/language/v1/roles.md)を参照してください。

## インラインアセンブラ

Kagura向けinline assemblyとして`asm`と`asm noreturn`を追加しました。\
`noreturn`はOnd codeへ戻らない外部制御移行に使います。

構文と制御フローは[Ond inline assembly仕様](../../specs/ond/language/v1/inline-assembly.md)、[Kagura v1 inline assembly仕様](../../specs/ond/targets/kagura-v1/inline-assembly.md)を参照してください。

## 初期化と配布

`ond init`は説明付きの`ond.toml`と`main.ond`を作成します。\
どちらかの作成先が既存fileまたはdirectoryの場合は上書きせず失敗します。\
Windows x64向けにInno Setup installerを追加し、配置先とPATH追加を選べます。\
既存installの更新と削除にも対応します。

`ond init`の出力は[command仕様](../../specs/ond/build/commands.md#ond-init)、manifest fieldは[`ond.toml`リファレンス](../manual/reference/manifest.md)を参照してください。

ユーザー向けガイドと仕様はZensicalの文書サイトから閲覧できます。\
GitHub Pagesでの公開に対応しました。
